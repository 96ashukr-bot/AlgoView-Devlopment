# Sparkbridge Innovations Website

Production-ready Next.js website for `bridgesparkinnovation.com`.

## Local Development

```bash
npm install
npm run dev
```

Local URL: `http://localhost:3010`

## Production Build

```bash
npm run build
npm run start
```

Contact enquiries are stored in `storage/enquiries.json`. Keep that file backed up or replace the API route with email/CRM delivery before heavy production use.
